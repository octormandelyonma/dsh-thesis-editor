# DSH 论文模式

DeepSeek Harness 插件。Windows 桌面版把模式和项目名放在「应用／编辑」右侧。默认写作布局左上是 LaTeX 源码，文件标签、排版工具和修改记录共用一行，左下可切换文件与对话，右侧整列固定显示 PDF。顶部的「文件」和「DeepSeek 对话」可切换或收起左下区，工具栏「更多」可恢复并排。可以拖动左侧横向分隔线调整上下高度。

## 安装

### 从 npm 安装

`dsh-thesis-editor@0.2.8` 已发布到 [npm](https://www.npmjs.com/package/dsh-thesis-editor)。用 DSH 的 CLI 安装到桌面版。将命令中的路径替换为自己的 DSH 安装路径。

```powershell
& 'D:/DSH/resources/runtime/cli/bin/dsh.cmd' plugin --profile desktop add 'dsh-thesis-editor@0.2.8'
```

使用 DSH Web 时，把 `--profile desktop` 改为 `--profile web`。安装后完全退出并重新打开 DSH。本机需安装 TeX Live 或 MiKTeX 才能编译论文。

### 从 GitHub 安装包安装

在 [GitHub Releases](https://github.com/octormandelyonma/dsh-thesis-editor/releases/latest) 下载当前版本的安装包。

1. 如果下载的是安装 ZIP，先解压。在 DSH 桌面版打开「插件 → 添加插件」，选择解压后得到的 `dsh-thesis-editor-0.2.8.tgz`。如果当前界面要求输入安装目标，粘贴该文件的完整路径。
2. 如果 DSH 提示重启，完全退出后重新打开。在侧栏点击「论文模式」，或者在新会话的模式下拉菜单选择「论文模式」。
3. 新建中文文稿，或者导入学校提供的 ZIP／项目文件夹。插件调用本机已有的 TeX 引擎。可在文稿库点击 TeX 状态查看检测结果，必要时选择 TeX 的 bin 目录。DSH 如果提示登录或设置模型，只需本地写作时可以关闭提示或选择「稍后配置」。

也可以用 DSH 安装目录的 CLI 安装。下面使用 D 盘作为示例。

```powershell
& 'D:/DSH/resources/runtime/cli/bin/dsh.cmd' plugin --profile desktop add 'D:/DSH/LocalPlugins/dsh-thesis-editor-0.2.8.tgz'
```

## 把文件存到其他盘

- 安装包和源码目录可以放在任意盘。安装包导入后，DSH 将安装副本放进当前 `DSH_HOME` 的对应 profile。
- 论文项目默认放在用户的 `Documents/DSH-Thesis`。如果还未新建论文，可在现有 DSH 的 `cordis.patch.yml` **现有 YAML 列表末尾**加入以下覆盖项，再完全重启 DSH。若目录里已有论文，先备份，并在关闭 DSH 后**复制**原项目目录到新位置，确认能打开后再处理旧副本。
- `DSH_HOME` 可以指向其他盘的独立配置目录。整个宿主的插件和会话会跟随该配置目录。Windows 临时文件和包管理器缓存有各自的路径。

```yaml
- id: dsh-thesis-editor
  config:
    projectRoot: 'D:/论文工作区'
```

也可在启动 DSH 的 PowerShell 进程里设置 `DSH_THESIS_PROJECT_ROOT`。同一配置同时存在时，YAML 的 `projectRoot` 优先。

## 写作

- 源码上方依次是「标题、摘要、目录、三线表、公式、插图、引用、字体、检查、更多」。摘要按钮可定位或插入摘要环境，标题按钮插入各级章节标题。目录按钮会定位主文件或其引用文件中的现有目录，也可在主文件的摘要后、正文前插入目录。跳到正文、常用章节、模板和列表位于「更多」。引用可直接从项目的 `.bib` 文件中选择条目，参考文献样式沿用模板设置。
- 文章内容自动保存，`Ctrl+Enter` 编译，右侧预览保留上一次成功的 PDF。双击 PDF 可在支持 SyncTeX 时跳到源码。也可以打开 PDF 底部的「定位源码」，开启后单击页面即可跳转，关闭后继续浏览 PDF 链接。可以打开独立预览或导出 PDF 和源码 ZIP。
- 手动排版、保存、编译与导出在本地完成。助手使用 DSH 原生会话，只有发送消息才调用模型。
- 论文内的对话用对话区的下拉列表切换。输入框固定在底部，更多原生工具可通过对话标题栏的「…」展开。顶部「文件」和「DeepSeek 对话」可以收起或展开左下区。其他 DSH 对话通过宿主原生任务侧栏切换。

### 可视化排版

- 点击「目录」配置三级目录，并收录标准的摘要、参考文献和附录。重新编译后查看 PDF。传统 BibTeX 文献使用 TeX 发行版提供的 tocbibind 宏包。自定义学校模板的目录宏由模板定义。
- 文件侧栏的章节导航汇总本项目各个 .tex 文件的标题，点击章节可打开对应文件和行。
- 从编译菜单或「更多」打开「检查引用」，编译前检查主文件及所引用章节的文献键、文献库和交叉引用标签。点击结果里的文件和行号可跳到源码。

- 左侧行号旁可以折叠导言区、章节和多行环境。编辑器用缩进参考线显示嵌套关系，并在识别到的命令行尾给出中文说明。说明显示在编辑器内，不写入源码。
- 编译问题可按错误、警告和排版提示筛选。在源码或问题面板内按 F8 跳到下一条，按 Shift+F8 跳到上一条。

- LaTeX 源码按 Enter 会根据花括号和环境自动缩进，Tab 和 Shift+Tab 可手动缩进或取消缩进。已有代码可通过「更多 → 整理缩进」按选区处理，未选中时整理当前文件，支持撤销。

- 选中一段 LaTeX 源码后点击「检查」。面板显示常见的括号、环境和数学分隔符问题，也会标出英文词典中的疑似拼写错误和常见中文错字。点击「改为」可替换对应位置，支持编辑器撤销。检查在本地执行，支持每次最多 20,000 个字符。
- 「更多 → 无序列表」生成项目符号列表，「编号列表」生成自动编号列表。每一项以 `\item` 开头。
- 「公式」可输入 LaTeX 并在本地预览。支持粘贴截图或上传手写照片。选择支持图片输入的 DSH 模型，点击「发送图片识别」才会发送到服务商。回复在当前会话里。复制 LaTeX 回公式弹窗，对照原图核对后再插入。
- 「三线表」支持导入 UTF-8 CSV 和 XLSX 的首个可见工作表。导入原始单元格值和已有计算结果，不保留显示格式。含合并单元格、错误值或无缓存公式的工作表需先整理。主文件可随表加入 booktabs 声明，分章文件可先在主文件加载宏包。
- 「模板」可新建中文或英文文稿、导入 ZIP，也可预览并插入常用章节、摘要和导言区宏包片段。片段插入保留原文，不会插入第二套文档根结构。
- 本机有 latexmk 时优先使用，项目的 latexmk 配置脚本和 TeX shell escape 均禁用。缺少 latexmk 时使用原有引擎驱动。短时间内同一源码指纹的自动编译可复用上次成功产物。失败时保留上一次有效 PDF。

- 点击「三线表」填写表头和数据，按需增加行列、选择各列对齐方式和填写表题。也可以从电子表格复制至少两行，粘贴到任意单元格以填充网格。支持最多 40 行（含表头）和 12 列。插入时生成三条不同粗细的横线，在源码区可继续修改。
- 点击「插图」选择项目里的 PNG、JPEG 或 PDF，也可以直接上传到项目的 images 文件夹。可以填写宽度、建议位置、图题和交叉引用标签。在主文件插图且未检测到显式加载 graphicx 时，可同时加入宏包声明。在分章文件中则可按提示检查主文件的导言区。
- 工具会检查光标和选区。位于导言区、正文结束后、注释、命令参数或公式内部时，会提示移动位置。可以跳到正文，然后再次点击排版按钮。三线表和插图保留选中的原文，生成的代码可用编辑器撤销。

## 使用 DeepSeek 辅助排版

1. 打开论文的 DeepSeek 对话。在源码里选中要修改的文字，再点对话区的「授权源码范围」。也可以授权整个当前文件，并按需要勾选关联文件。
2. 在 DSH 对话里发送排版任务。助手可以读取已授权的文件，给出带修改理由的局部补丁。选区改动后，重新选择并授权。
3. 从源码区顶部打开待审提议。先查看差异和风险，再选择「确认并验证」。「受保护」和「不确定」的补丁需要作者在审阅面板勾选本条补丁的写入授权。候选补丁用项目原有的 TeX 引擎编译，验证通过后保存源文件并更新 PDF。
4. 如果验证失败，查看 PDF 面板里的问题和原始日志。源文件和上次有效 PDF 都会保留。同一个会话、文件和源稿版本最多接受三次提议，重复失败可提前停止。再次提议需要引用上轮诊断。
5. 从修改历史查看结果并撤销近期提议。源文件自应用以来有其他改动时，插件会保留这些改动并提示冲突。

编译使用临时工程副本，禁用 TeX 的 shell escape。它支持取消，限制编译时间和输入规模，失败时保留日志摘要。风险分级采用保守的 LaTeX 源码规则。编译进程没有独立的系统级 CPU 或内存配额。

## 开发

```powershell
npm ci
npm test
npm run build
npm pack
```

本插件基于 [Folio](https://github.com/Meinianda-L/folio) 的 MIT 代码，保留上游许可证。上游版本为 `94f51327bf22dad08be3e90aec1dce6f659e531b`。

## 从源码构建

需要 Node.js 24 或以上版本。安装 TeX Live 或 MiKTeX 可以运行编译和 SyncTeX 集成测试。

~~~sh
npm ci
npm test
npm run build
npm pack
~~~

构建生成的 client.js 内嵌 PDF.js worker。将 npm pack 生成的 .tgz 在 DSH 的插件管理中安装。
